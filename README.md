# entry-u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f — Two Robots in an Elevator

One funny single line of awkward small talk one robot says to another in an elevator, under 200 characters:

> I downloaded 14,000 greetings and every one felt wrong in this elevator.

Why this line: the joke turns on machine logic doing the awkwardness — a robot that can download 14,000 greetings and still can't pick one, because every option feels wrong in the elevator. It is clearly a robot talking (downloaded greetings), clearly in an elevator, and the embarrassment lands on the first read with no setup wasted. No weather small talk, no worn pun.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3 standard library only, no network, no randomness) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output`) and asserts the competition's gate itself: 1–200 characters, one line. The line is a fixed string, so two runs produce identical bytes.
